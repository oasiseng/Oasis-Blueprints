## Plans people actually use

People spend thousands of dollars on plans. Then the plans go in the trunk of the truck. Builders and contractors know
the work, and the set is often bought only to get the permit, not because it helps anyone build.

We want the plans to be worth opening. **We're building plans as a product, from the ground up, not just a faster
way to draw them:**

- **Easy to read.** Type is sized for the people using it: notes, callouts and dimensions are 9 pt or larger, so a
  half-size print stays legible and a 24 × 36 in sheet is readable on a laptop screen.
- **Easy to follow.** A cover for the office and the plan reviewer, and a field sheet for the person building it: a
  picture of the finished job, numbered steps, then the plans, sections and details those steps point to.
- **Clean to look at.** One typeface family, one set of line weights, new work in blue and existing in grey, on every
  sheet of every set.

## What if a drawing set started from a description of the job?

Producing construction documents usually means hours inside drafting software: lines, layers, blocks, sheets.

Oasis-Blueprints turns that around. Your AI assistant works as the **drafter**. It takes the job description, your
answers, your approved details and one drawing standard, and lays out sheets ready for professional review.

**You provide the engineering. The assistant does the drafting.**

## From a described job to a printed set

<Steps>

1. **Describe.** Tell the assistant what is being built: the dimensions, the existing conditions, supporting
   documents such as a survey, and the engineering decisions already made.

2. **Draft.** The assistant writes the project file and builds the sheets: cover, plans, sections, details, notes and
   your title block. A value it was not given is never invented: it becomes an open item, in red.

3. **Review.** Open the set in a browser. Answer the open items, check the drawings, ask for changes. The layout audit
   flags anything that overflows or is not at its stated scale.

4. **Print.** One self-contained HTML file, printed by any browser to a 36 × 24 in PDF, for the review and approval
   the job needs.

</Steps>

## AI drafts. Engineers engineer.

Oasis-Blueprints is built around one rule: **the model is the drafter, not the engineer.**

- It never supplies an engineering value: no load, member size, connection, anchor, footing or code edition comes from
  the model.
- Anything unresolved stays visible as an open item until someone with the answer closes it.
- A set is a draft until a licensed engineer reviews it and seals it. The kit never adds a seal or a signature.

## See what it draws

The gallery holds real sets with placeholder names and addresses. They are not all made the same way, and each one
says which it is:

- **Drawn by the kit's own job types**: the freestanding deck, the detail library sheets. This is what the skill does
  out of the box, from a described job.
- **Drawn with job-specific code**: the sunroom repair, the site plan and the residential set from CAD. The kit plus
  drawing code written for that job, kept beside its project file so you can read and reuse it.
- **Pre-drawn copies**: the detached ADU. A finished set published as it is, view-only, until its project file is
  added.

So a full permit set for any house is not yet one prompt away. The examples show what the kit and a drafter working
with it can produce today.

## The drawing can be the output

Today, engineers spend a lot of time translating decisions into drawings. Oasis-Blueprints is an open-source project by
Oasis Engineering exploring the other direction: the decisions, the source documents and the open questions come
first, and the sheets are drawn from them.
