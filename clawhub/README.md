# ClawHub edition

`oasis-blueprints/` is the drawing skill packaged for [ClawHub](https://clawhub.ai), the skill registry for OpenClaw
agents. It is generated from `skills/oasis-blueprints/` and `library/` by `scripts/build_clawhub.py`: do not edit it by
hand.

Publish it with the ClawHub CLI from a clone of this repository, upload the folder on the ClawHub website, or import it
from GitHub (choose `clawhub/oasis-blueprints/SKILL.md` if the importer lists several skills).

ClawHub publishes every skill under MIT-0, so this folder has no license file of its own. The rest of this repository
is under the MIT License. The bundled Barlow fonts keep the SIL Open Font License (`oasis-blueprints/assets/fonts/OFL.txt`).
